RAASA – An Exquisite Indian Dining Experience

RAASA is a modern luxury Indian restaurant website designed to showcase an elegant dining experience through beautiful visuals, sophisticated design, and interactive features.

The website combines traditional Indian dining inspiration with a modern digital experience, making it easy for customers to explore the restaurant, discover its menu, submit reservations, and share their dining experiences.

🌟 Features

- Modern Luxury Design: Elegant interface with a premium burgundy, charcoal black, champagne gold, and warm ivory colour palette.
- Responsive Layout: Optimized for desktop, tablet, and mobile devices.
- Home Page: Attractive hero section introducing the RAASA dining experience.
- Our Story: Section highlighting the restaurant's identity and dining philosophy.
- Food Menu: Signature Indian dishes with descriptions and pricing.
- Gallery: Visual showcase of food and restaurant ambience.
- Table Reservations: Interactive reservation form for customer booking enquiries.
- Customer Reviews: Interactive five-star rating and comment system.
- Review Statistics: Average rating, total reviews, and star distribution.
- Contact & Location: Restaurant location, contact information, and directions.
- Social Media Integration: Links to Facebook, Instagram, X, and YouTube.

🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite
- JavaScript
- HTML5
- CSS3

🔌 Integrations

- Web3Forms: For receiving restaurant reservation enquiries through email.
- Supabase: For storing and retrieving customer reviews.
- Vercel: For website hosting and deployment.
- GitHub: For source code management and version control.

Note: Integrations are being configured and tested as part of the project development.

🎨 Design Concept

RAASA follows a modern luxury restaurant aesthetic.

- Primary colours: Deep Burgundy and Charcoal Black
- Accent colour: Champagne Gold
- Background colour: Warm Ivory
- Brand personality: Elegant, sophisticated, welcoming, and authentic.

💻 Installation and Setup

To run the project locally:

1. Clone the repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory:
   
   cd raasa-restaurant

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in your terminal.
